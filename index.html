      How it works. Every morning the models are retrained on all data up to that day and forecast the next day's hourly prices, using only information available before the day-ahead auction closes at noon. Each forecast is stored with the time it was made and never changed afterwards. Days before the live start ("backfill") were computed afterwards with exactly the same setup. The forecast range for a day comes from how far the forecasts missed in the eight weeks before it (per hour of the day); it uses only misses that were known when the forecast was made. The gas price is not used: there is no free daily source for it. Realised prices are not shown; only how far the forecasts were off.

      Sources. Demand forecasts: ENTSO-E Transparency Platform (transparency.entsoe.eu), via entsoemcp.com. Weather: Open-Meteo (CC BY 4.0). CO2: SparkChange Physical Carbon EUA ETC. Headlines: GDELT, labelled by an open language model (Qwen2.5 7B).
